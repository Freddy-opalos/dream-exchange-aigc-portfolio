# 制作说明与面试讲述提纲

## 我做了哪些选择

1. 使用大模型辅助展开剧本与视觉方案，围绕画风一致性、剧情逻辑和起伏筛选。
2. 对皮肤过度光滑、质感偏塑料的角色结果不满意，改用三渲二方向并调整提示词约束。
3. 发现人物飞过头顶时，另一人物没有转身、视线衔接不合理，尝试修改提示词及调整切镜。
4. AI配音的语气词和情绪表达尚需处理，最终片花还未剪辑完成。

## 可以现场展示

- 两段原始视频素材、角色/场景设定。
- 画风提示词文档和镜头台本参考。
- 30秒素材展示短片。

## 仍在推进

最终选镜、跨镜画风统一、配音与叙事剪辑。不能将素材展示片称为已完成的90至120秒参赛片花。
