## 制作实践

- 视觉选择：围绕三渲二风格筛选角色与场景，用提示词约束人物质感，淘汰过度光滑、风格不符的候选结果。
- 镜头迭代：关注人物视线、动作朝向和镜头衔接，尝试修改提示词与切镜方案。
- 声音与剪辑：尝试AI配音，关注语气词与情绪表达；可使用剪映处理拼接、字幕、配乐与音量。
- 工具：ChatGPT、WorkBuddy、TapNow、即梦、Midjourney相关提示词工具、剪映。
